# cognitive-reflection · 认知反思与思维校准

> 一个给 LLM Agent 用的思维训练 Skill。它不陪你聊人生，它把你模糊的感受拆成**能被现实打分的命题**，再用对账结果训练你的判断力。
>
> An evidence-informed, calibration-first reflection skill for LLM agents. Instead of "helping you feel understood", it turns vague feelings into **falsifiable bets**, then trains your judgment by scoring them against reality.

---

## 为什么做这个

市面上大多数"AI 陪你反思"的产品，有三个通病：

| 通病 | 后果 |
|---|---|
| 只做共情，不做校准 | 说完很舒服，三天后原样复发 |
| 一上来就分析原因 | 在情绪高点做归因，等于喂养反刍 |
| 用"成长型思维""换个角度"这类话术 | 听起来对，无法执行，平均效应很弱 |

这三个通病有共同的根：**把反思当成"理解自己"，而理解不会改变行为。**

这个 Skill 换了目标：**从"解释自己"到"校准自己"**。

一次合格的对话结束时，你手上应该有：

1. 一条**能被现实判真假的命题**（不是"我最近状态不好"，而是"下周三评审会上我会被问住数据口径"）
2. 一个**数字**（我押 65%）
3. 一个**反证条件**（如果两周内预算没批下来，我就错了）
4. 一个**触发条件具体的动作**（如果评审前一天晚上八点我还在改 PPT，我就把口径那页单独过一遍）

没有这四样，这次只是聊天。

## 核心设计

### 引擎：四步

```
看清  →  拆开  →  赌一把  →  装回去
```

| 步 | 做什么 | 产出 |
|---|---|---|
| **看清** | 只描述摄像机能拍到的部分；热态先用第三人称拉开距离 | 一句话事实 + 强度分 |
| **拆开** | 按四维评估（相关性 / 确定性 / 归因 / 应对力）把感受拆成 1-3 条命题 | 可判真假的句子 + 正反证据 |
| **赌一把** | 押百分比、写反证条件、定日期、查基准率 | 一张预测卡 |
| **装回去** | if-then 计划 + 一个环境改动 + D1/D7/D30 对账 | 一条可携带的规则 |

### 五条设计公理（决定它拒绝做什么）

1. **远迁移基本不存在**——认知训练的二次元分析显示，控制发表偏倚与安慰剂后远迁移效应归零。所以不承诺"提升思维层级"，只承诺"具体场景里多一个程序"。
2. **只有校准可以通用**——元认知校准可训练，且能迁移到未训练任务。所以校准是唯一通用目标。
3. **反思既可以是药也可以是病**——反刍分两支：问题导向的内省（产出新信息）与 brooding（反复对照未达成的标准）。后者预测抑郁。连续三轮无新信息，就停。
4. **情境强于意图**——所以"想通了"必须配一个环境改动，否则三天后复发。
5. **说理不改变人，程序改变人**——立场偏向与智力几乎无关，且不跨领域通用。所以只给清单、数字、记录，不给"你要理性一点"。

### 与常见做法对比

| | 常见 AI 反思 | 本 Skill |
|---|---|---|
| 目标 | 让你理解自己 | 让你的判断被现实校准 |
| 产出 | 一段洞察 | 一张能被打分的预测卡 |
| 情绪高时 | 继续分析 | 停止分析，只拉开距离 |
| 给建议 | 直接给 | 先问"要不要听"，被拒就收回 |
| 结束方式 | 总结陈词 | 约定对账日期 |
| 训练 | 无 | 四周协议 + 三个可测指标 |

## 安装

把 `SKILL.md` 和 `references/` 一起放进你的 skills 目录。

**Claude Code / 兼容 Agent Skills 的框架**

```bash
cd ~/.claude/skills
git clone https://github.com/chase1960/cognitive-reflection.git
```

**豆包 / 其他本地 Agent**

复制到对应的 `skills/` 或 `user_skills/` 目录，确保 `SKILL.md` 在目录根部，`references/` 是它的同级子目录。

**纯手动使用**

不需要 Agent 也能用：把 `references/training-protocol.md` 的四周协议打印出来，按周做。这门训练的核心是记账表和对账，不是对话。

## 怎么用

**1. 带着一件事来**

> 「我最近特别不想上班，说不上来为什么。」

Skill 会先问"哪一天最不想去"，而不是"你为什么不想上班"。

**2. 带着一个决定来**

> 「要不要接这个项目。」

跳过分析，直接算：最坏损失能不能承受、哪个选项保留更多退路、如果一年后后悔最可能是因为什么。

**3. 想做长期训练**

> 「我想练判断力。」

进入四周协议：第 1 周练命题化，第 2 周练概率化，第 3 周练反证搜索，第 4 周练归因分摊与环境改动。每周 3 次，每次 5-10 分钟。

完整示例见 [`examples/full-session.md`](examples/full-session.md)。

## 证据基础

结论都标了强度，也标了效应量。**方向可靠 ≠ 量级可靠。**

| 结论 | 强度 | 关键数字 |
|---|---|---|
| 认知训练远迁移接近于零 | A | 偏差校正后效应≈0 |
| 元认知校准可训练且可迁移 | B+ | Brier 分改善，迁移到未训练任务 |
| 反刍分 brooding / pondering 两支 | A | brooding 预测抑郁，pondering 不 |
| 自我抽离有助于调节 | B | g≈0.19（25 个实验）vs g≈0.52（另一元分析）— 说法不一 |
| 非第一人称自我对话 | B | 7 个实验，N=585 |
| if-then 计划 | A- | d≈0.65（94 项测试）；偏倚校正后 0.15–0.35 |
| 立场偏向与智力无关 | A | N≈1484，几乎无相关 |
| "认知扭曲"不是逻辑错误 | B | 概念分析 + 进化功能论述 |

完整表格、争议与来源链接见 [`references/evidence-base.md`](references/evidence-base.md)。

**特别说明**：本 Skill 明确不采用若干流行但证据薄的说法（成长型思维万能论、10-10-10 法则、学习风格、MBTI 用于自我认知等）。原因写在证据文件里。

## 局限

- **不是治疗。** 不做诊断，不替代心理咨询或精神科。出现风险信号时退出反思模式，见 `SKILL.md` 第七节。
- **不承诺效果。** 所有效应都是群体平均，落到具体的人可能有用也可能没用。真正的判据是你自己的对账记录。
- **需要真实反馈。** 在反馈慢或噪音大的领域（比如"我这个人是否讨人喜欢"），校准练不起来。这一点无法靠话术解决。
- **文化语境。** 写作与示例基于中文语境；概念本身跨语境可用。
- **作者不是临床心理学家。** 这是一个工程化的对话协议，不是一个疗法。文献引用以原文为准，若发现引用不当，欢迎提 issue。

## 贡献

欢迎提 issue，尤其是这三类：

1. **证据纠错**：某条结论的效应量或边界说错了。
2. **反模式补充**：你遇到过的、这个 Skill 处理得很糟的对话。
3. **训练协议的现实测试**：你真的按四周跑过吗？哪一周最容易掉？

改 `SKILL.md` 时请保持两条约束：**不新增承诺**（不承诺提升智力/人格/心态），**不新增无程序的建议**（每条建议都要能落到一个 30 秒动作）。
