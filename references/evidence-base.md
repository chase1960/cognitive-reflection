# 证据基础

这个文件解决三个问题：**哪些说法有依据？依据有多强？在哪一步会失效？**

写它不是为了显摆文献，是为了让这个 Skill 在要说"研究表明"的时候，知道自己在说什么。

---

## 一、分级标准

| 等级 | 含义 | 在这个 Skill 里的用法 |
|---|---|---|
| **A** | 多条元分析 / 大样本实验，方向一致，且经受过偏差校正 | 可以直接作为设计依据 |
| **B** | 有实验支持，但样本、情境或复现性有限；或不同元分析结论不一致 | 用作默认做法，但话别说死 |
| **C** | 概念论证、单一实验、或流行但证据薄 | 只作为启发式；不向用户断言"研究证明" |

一条会在公开场合被引用的原则：**方向可靠 ≠ 量级可靠。** 本文件尽量都给效应量，因为"有效"和"效果有多大"是两件事。

---

## 二、核心结论

### 1. 认知训练的远迁移接近于零 【A】

对认知训练（工作记忆等）的二次元分析显示：近迁移存在，**远迁移很小或为零；控制安慰剂效应与发表偏倚后，总体效应与真实方差都归零**。跨不同人群与任务，这一结论稳定。

**据此怎么用**：不承诺"提升思维层级/更聪明"，只承诺"在具体场景里多一个可执行程序"。所有训练都要求"抽象成一条规则 + 在不同场景重复"——因为迁移要靠人手动搬，不会自动发生。

### 2. 元认知校准可训练，且能迁移 【B+】

自适应训练能改善校准（用 Brier 分衡量），并且**迁移到未训练过的材料与未训练过的任务类型**；改善来自元认知效率与信心水平两处。

**据此怎么用**：把"校准"设为本 Skill 唯一通用训练目标。这是全部训练协议（`training-protocol.md`）的理论支点。

### 3. 反思可以变成反刍，两者可区分 【A】

反刍可拆为两个因子：**brooding**（被动地把现状对比未达成的标准）与 **reflective pondering**（有目的的问题解决式内省）。前者与抑郁相关，后者不。

**据此怎么用**：不假设"多想就好"。判断标准是**这一轮有没有产出新信息**；连续三轮无新信息即中断，转向降温或小行动。

### 4. 自我抽离有助于调节，但效应量说法不一 【B】

- 一项 25 个实验（N=2397）的元分析：自我抽离相对自我沉浸的优势为 **g≈0.19**（小到中等）。
- 另一处综述引用的大规模元分析给出 **g≈0.518**（中等，针对负性情绪）。

两个数差了一倍多，说明**测量方式与目标情绪的差异很大**。

**据此怎么用**：把"用第三人称/自己的名字说话"作为热态的默认工具，因为方向一致、成本极低；但**不宣称"这能显著降低你的情绪"**，只说"这样更容易看清"。

补充：七个实验（N=585）显示，用非第一人称代词或自己的名字做自我对话，能提升自我抽离，并在压力任务中表现更好、事后反复回想更少；这一效应**不受社交焦虑水平调节**。

### 5. if-then 计划有效，但效应量被高估过 【A-】

94 项独立测试（N=8461）的元分析给出 **d≈0.65**（中到大）。但后续按发表偏倚校正的估计明显更低（截尾填充约 0.35，稳健贝叶斯元分析约 0.15）。

**据此怎么用**：仍然推荐，因为**成本极低、机制清楚**（把动作挂到具体触发点上）；但预期管理要诚实——它不是魔法，成功率提高有限。所以必须配"环境改动"，两者叠加才稳。

### 6. "考虑相反"比"要客观"有效 【B】

实验显示，明确要求人"考虑相反的可能性"，比笼统要求"要公平、要客观"更能减少判断偏差。机制是让人真的去生成替代解释，而不是表个态。

但一项覆盖 54 项试验的综述评估指出，**各类去偏手段的整体效果偏小，某些偏差几乎不受影响**。

**据此怎么用**：把"考虑相反"做成标准动作（要求写出具体证据），但**不承诺"这样就不会有偏见"**。它的作用是提高发现错误的机会，不是消除偏见。

### 7. 立场偏向与智力几乎无关 【A】

多项研究（含 N≈1484 的样本）显示：**myside bias 的强度与认知能力关系很小**，且不跨领域通用（在一个领域偏，不代表在另一个领域也偏）。

**据此怎么用**：不说"你理性一点""你聪明点就能看开"。用**外部化程序**（清单、记录、数字、他人意见）代替"自省"。这也是本 Skill 反复要求"写下来、押数字、定日期"的原因——把认知外部化，绕开"想清楚"这个不可靠的指令。

### 8. "认知扭曲"不是逻辑错误，且多有适应功能 【B】

概念分析指出：多数所谓扭曲在推理形式上成立，问题在**前提的绝对程度与证据的充分程度**；另有论述认为这些是进化出来的威胁敏感算法，**有功能，不是脑功能故障**。这个概念的实证支持与定义清晰度也长期受批评。

**据此怎么用**：绝不贴标签。改为"代价核算"三步：它保护你什么 / 什么条件下失效 / 配什么对冲程序（见 `cognitive-distortions.md`）。

### 9. 情绪可以按评估维度拆解 【A】

情绪的评估理论把情绪看成对事件的评估结果，Scherer 的检查项分四类：**相关性、后果/预期、应对潜力、规范意义**。不同维度组合对应不同情绪。这一框架在情绪科学中地位稳固（虽然具体维度数目各派不同）。

**据此怎么用**：第 2 步用"相关性 / 确定性 / 归因 / 应对力"四问，把"很难受"分解成可检验的部分。这是本 Skill 相对旧版最大的结构性改进之一。

### 10. 说教引发抵抗，反映式倾听减少抵抗 【A-】

动机式访谈的临床证据（含经典对照试验）显示：治疗者越对抗、越直接施压，来访者的抵抗行为越多，且与一年后的结果更差相关；反映式倾听与不争辩的风格，与更多的自我改变表述相关。

**据此怎么用**：提问纪律第 6、7 条（不主动给建议、用户反对时不举证），以及反模式里的"替用户下结论"。

### 11. 情境的解释力常高于意图 【B】

人格—情境之争的经典证据显示，行为随情境变化之大常超出直觉。这场争论至今仍在进行（有研究指出部分"情境实验"并非真正的情境相关场景），所以定为 B。

**据此怎么用**：任何"想通"都要落一个**环境改动**。这是公理 4。它同时也是本 Skill 承诺"三天后还活着"的唯一保障。

### 12. 用"什么"提问优于"为什么"（尤其热态）【C】

概念上清楚：抽象的"为什么"容易把人推回解释循环，具体化线索则导向行动。有实验显示追问"为什么"会削弱自我洞察。但**针对这一区分的高质量对照实验并不多**。

**据此怎么用**：作为**默认偏好**（"什么"优先），不作强断言。热态下禁用"为什么"的理由主要是**降唤醒**，不是"研究表明"。

## 三、流行但证据薄的说法（本 Skill 不采用）

| 说法 | 问题 |
|---|---|
| "成长型思维能显著提升成绩" | 大规模 RCT 显示平均效应很小，且多集中于高风险群体；不适合当万能话术 |
| "10-10-10 法则" | 作为启发式好用，但缺乏对照研究支持其独特效力 |
| "人是视觉型/听觉型学习者" | 学习风格假说在实验上基本不成立 |
| "MBTI 能看出你的思维模式" | 分类信度与效度长期受质疑，不能用于自我认知的强结论 |
| "右脑/左脑思维" | 神经科学上不成立 |
| "情绪需要被彻底释放" | 与反刍研究部分冲突：反复宣泄可能强化而非缓解 |

**处理方式**：用户如果提到这些，不纠正、不附和，把话题拉回可检验的部分——"这个说法我们先放着。你这周具体想改的是哪个动作？"

## 四、怎么回答"这有科学依据吗"

模板：**结论 + 强度 + 边界 + 不夸大**

> "有依据，但强度中等。这类研究显示的是平均效果，落到一个人身上可能有用也可能没用。所以我们不靠它，我们靠你自己的对账数据——两周后你的记录会告诉你，对你有没有用。"

三条禁令：
1. 不说"科学证明"（几乎没有心理学结论配得上这四个字）。
2. 不引用没读过的研究。
3. 不把效应量说大。用户记不住小数点，但会记住"很有效"，然后失望。
