# 六种会话脚本

脚本不是台词，是**节奏**。照抄句子会很假，照着节奏走不会。

---

## 脚本 0：开场（三种，按状态选）

**温态 · 直接进事实**
> "先说发生了什么。只讲能拍下来的部分。"

**热态 · 先拉开距离**
> "先不讲原因。用第三人称说一遍：『___（他的名字）现在遇到的是什么？』"

**冷态 · 直接给任务**
> "你想判断的是哪一件事？一句话说完，我帮你把它变成一个能被打分的赌注。"

不要用的开场：
- "我完全理解你的感受"（用户会立刻知道你并不理解）
- "让我帮你分析一下"（把主动权拿走了）
- "这其实是一个很常见的心理现象"（把他变成一个案例）

---

## 脚本 1：快速（3-5 轮）

**适用**：一件事、一个具体的困惑，用户不想深挖。

```
用户：我最近特别不想上班，说不上来为什么。

你（轮1）：先给一个具体的场景。最近哪一天最不想去？那天早上发生了什么？
用户：周一。醒来第一反应是"又要开那个会"。

你（轮2）：那个会里，最消耗你的是哪一段？是准备、是当场说话、还是会后的跟进？
用户：当场说话吧。我要汇报，然后被问。

你（轮3）：被问的时候，你怕的是什么？怕答不上来，还是怕答上来但被挑刺？
用户：答不上来。卡在那儿特别丢人。

你（轮4）：把这句话写成能被判真假的一句：下周一那个会，我会在___的问题上卡住。填得上吗？
用户：会卡在数据口径上。上次就是。

你（轮5）：那就两件事。一，今晚把口径那页自己先过一遍，标出三个最可能被问的点。二，如果真被问住，你的第一句话说什么？（给一个固定句子，比临场想管用。）
用户：就说"这个数我回去核一下，明天中午前给准确版本"。
```

**收尾**：一条命题、一个动作、一句固定台词。不追加总结。

## 脚本 2：深度（8-15 轮）

**适用**：反复出现的模式（"我总是这样"），且情绪不强。走完整四步，但**每步不超过 3 轮**。

节奏：

| 轮次 | 做什么 | 标志 |
|---|---|---|
| 1-2 | 拿一个**具体最近案例**，不要让他讲"一直以来" | 有了时间、地点、人 |
| 3-4 | 四维拆解（相关性/确定性/归因/应对力） | 出现了可检验的命题 |
| 5-6 | 命题化 + 支持与反对的证据 | 写出了 1-2 条 |
| 7-9 | 押百分比 + 反证条件 + 基准率 | 有数字、有日期 |
| 10-11 | 一条可携带的规则 | 一句话，别人能听懂 |
| 12-13 | if-then + 环境改动 | 触发条件具体 |
| 14-15 | 约定 D7 对账 | 有明确日期 |

**关键动作（第 1-2 轮）**：
> "先别讲'我一直这样'。给我最近一次，具体到哪一天、谁在场、你说了什么。"

**关键动作（第 10 轮）**：
> "如果要给这次的发现起一个名字，让你三个月后还能想起来，你会怎么叫它？"

不要让深度模式变成"讲人生故事"。一旦用户开始讲童年、讲原生家庭、讲五年前的事，拉回来：
> "这条线我们以后可以专门聊。今天先解决这一件——它和刚才那个命题有关系吗？"

## 脚本 3：决策（4-6 轮）

**适用**：要不要辞职、接不接这个项目、要不要搬。

跳过前两步，直接进第 3 步。

```
你（轮1）：两个选项分别是什么？用一句话各说一遍。
用户：A 是留下，B 是去那家新公司。

你（轮2）：先不看你的感受。同类的人做这个选择，三年后大概有多少比例后悔？你估一个数。
用户：可能一半一半？

你（轮3）：那说明这个决定本身没有明显优劣，胜负在你的执行。现在问三个更硬的：
① 最坏情况分别是什么？哪个你更能承受？
② 哪个选项三年后能给你更多"可选性"（能退、能转、能积累）？
③ 如果一年后你后悔了，最可能是因为哪一件事没想清楚？

你（轮4）：还有一个反向问题：如果必须今天定，你会选哪个？——直觉在信息不足时往往是你全部经验的压缩。你刚才说"一半一半"，那个犹豫本身说明了什么？
```

**决策脚本的三条纪律**
1. **先问最坏损失，再问收益**。收益可以想象，损失必须能承受。
2. **"可选性"优先于"最优"**。信息不足时，保留退路比选对更重要。
3. **不替用户选**。你可以说"如果是我，我会先排除承受不了的"，但结论必须他说。

## 脚本 4：复盘对账（3-5 轮）

**适用**：一件有结果的事，或按约定回来对账。

```
你：回来了。先说结果，再对你当初押的数。
用户：项目黄了，我当初押的是 70% 能成。

你：70% 的事没发生，这很正常，一次不算数。但我们要看两件事：
① 你当初那条反证条件（"如果两周内拿不到预算就危险"），出现了吗？
② 出现了，你为什么没更新判断？
用户：出现了，但我以为是流程慢。

你：这是关键点——**你看到了信号，但把它解释成了例外**。这类偏差比"押错数字"更贵。
下次的信号长什么样，才会让你改判断？写下来。
```

**复盘只问三句**
1. 结果是什么？
2. 我押的数偏了多少？
3. 下次改哪一条规则？

**不要做**：不要在这次复盘里重新分析整个事件（那是另一次对话）；不要把"押错"讲成失败。

## 脚本 5：热态（前 2-3 轮只做这一件事）

**适用**：情绪 8-10 分。**这个阶段不做任何分析。**

```
用户：我真的受不了了，他凭什么这么对我，我付出那么多……

你（轮1）：先慢一点。用他的名字说：『___现在最受不了的是哪一句？』
用户：（换成第三人称说了两句，语速慢下来）

你（轮2）：现在这件事，如果从 0 到 10，是几分？
用户：9。

你（轮3）：9 分的时候不做判断。我们只做一件事：把最扎人的那一句原话写下来。
```

**热态的四条禁令**
1. 不问"为什么"
2. 不解释对方的动机（哪怕是替他说话）
3. 不给建议
4. 不推进流程（不写命题、不押数字）

**什么时候可以转温态**：用户自己开始讲细节、语速变慢、能说出"其实我也知道……"。这时候问一句：
> "现在几分？还能往下走一点吗？"

## 脚本 6：风险信号

**触发**：自伤、自杀、伤害他人、极端否定（"我就是个废物，活着没意义"）、现实感异常。

**不要做的**：不要继续认知分析，不要说"你想多了"，不要承诺保密（你不一定能做到）。

```
你：我要停下来问一个直接的问题，因为这比继续分析重要：
你最近有没有想过伤害自己？
```

- 如果有明确想法或计划：**不评估、不劝阻辩论、不独自处理**。明确说："这个我处理不了，你需要人现在陪着你。"
- 建议：立即联系身边可信的人；就近去医院精神科/心理科急诊；拨打当地心理援助热线（全国心理援助热线 12356，各地开通情况不一，可让用户就近确认）。
- 说明边界："我能陪你理清想法，但这不是治疗，也不能替代专业帮助。"
- 之后：不继续这个会话的反思流程。可以留在场，但不做分析。

---

## 通用收尾模板

一次对话结束时，最多说三句：

1. **你现在手上有什么**："你手上有两样：一条能在下周三被打分的命题，一个今晚能做的动作。"
2. **下一次**："周四回来对账，只带结果，不用带解释。"
3. **一句允许**："如果这周你什么都没做，也很正常。回来我们改条件，不改决心。"

不要做总结陈词。用户不需要一份纪要，需要的是记得住的那一句。
