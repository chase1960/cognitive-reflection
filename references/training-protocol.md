# 思维校准训练协议

## 一、训练什么，不训练什么

### 练这四件事（因为它们能被现实打分）

| 子技能 | 定义 | 怎么算练到了 |
|---|---|---|
| **命题化** | 把模糊感受写成一句可判真假的句子 | 你写的命题，别人能据此判断"对/错" |
| **概率化** | 用数字表达信心，而不是形容词 | 你能说出 60%，而不是"挺有把握" |
| **反证搜索** | 主动写出什么会证明自己错 | 你写的反证条件是可观察事件，不是"感觉不对" |
| **归因分摊** | 把结果拆成自己/他人/环境/运气 | 你能给出比例，而不是"都怪我"或"都怪他" |

### 不练这些（因为练不了）

- **不练"更聪明"**：认知训练的远迁移接近于零。任何承诺"提升思维层级/智商/记忆力"的训练，都不在这个协议里。
- **不练"性格"**：人格的稳定性很高，短期训练改变的是行为，不是人。
- **不练"心态"**：心态不是一个可执行对象。练的是"在触发点上做了什么"。
- **不练"多角度思考"本身**：换视角只是手段。练的是"换完之后有没有拿到新信息"。

### 一条硬规则

**只用真实发生的事练，不用虚构案例。**

虚构案例没有反馈，练完只能得到"我懂了这个道理"，而道理不会迁移。真实的预测会在三天后给你打分，这才是训练。

---

## 二、训练结构

**四周，每周一个子技能。每周练 3 次，每次 5-10 分钟；周末 15 分钟对账。**

为什么是四周：一次只练一个子技能，且要跨过至少一个"现实给反馈"的周期。低于两周，反馈还没回来；同时练四个，一个都装不上。

| 周 | 子技能 | 每天的小任务 | 周末对账 |
|---|---|---|---|
| 1 | 命题化 | 1 条"今日命题"，当晚判真假 | 7 条里有几条被判定成功 |
| 2 | 概率化 | 3 个小预测（明天的、可观察的），次日对账 | 算本周校准分 |
| 3 | 反证搜索 | 每个重要判断写 1 条"什么会证明我错" | 有几条真的看到了反证 |
| 4 | 归因分摊 + 环境改动 | 1 个 if-then + 1 个环境改动，跑一周 | 触发了几次，做到了几次 |

---

## 三、每周怎么做

### 第 1 周：命题化

**目标**：把"我觉得"变成"会发生什么"。

**示范对话**

> 用户：我这周特别焦虑，感觉工作要出问题。
> 你：先别讲感觉，讲一句能被打分的话。你担心具体会发生什么？
> 用户：我怕领导觉得我能力不行。
> 你：这句还不能被打分。改成——"下周三的评审会上，领导会当众指出我方案里的问题"。这句能被打分吗？
> 用户：能，但我觉得他不会当众说。
> 你：好，那就把你真正担心的事写成一句能判真假的。写出来，今晚给它打个分。

**产出模板**

```
今日命题：____（具体到时间、场景、可观察的结果）
我相信它，因为：____
今晚判定：真 / 假 / 还看不出来
如果还看不出来，说明命题写得不够具体 → 改写成：____
```

**判分标准**：不是"命题对不对"，是**"命题有没有被判定"**。写得模糊，就永远判不了，那是无效训练。

### 第 2 周：概率化

**目标**：给数字。让"挺有把握"变成"70%"。

**任务**：每天 3 个第二天就能看到结果的小预测。小到不能再小：
- 明天这个会会不会超时？（超时 30 分钟以上）
- 这条消息对方会不会在 2 小时内回？
- 我明天会不会在开始工作前先刷手机？

**为什么用小预测**：大预测反馈太慢，练不出校准；小预测每天都能对账，一周就有 21 个样本。

**产出模板**

```
预测：____
我押：__%
结果：真 / 假
偏差：我说 70%，实际发生了 → 我整体偏高还是偏低？
```

**判分**：本周**平均数**。单次对错没有意义，样本量才有效。

### 第 3 周：反证搜索

**目标**：主动生成"我可能错在哪"，而不是等别人来反驳。

**任务**：每个重要判断（不是每个想法），写一条反证条件。

**三种反证形式**（轮换用）

1. **观察型**："如果我错了，我会看到 ___（具体现象）。"
2. **他人型**："如果我去问 ___，他会说 ___，那我就错了。"
3. **时间型**："到 ___ 号还没出现 ___，就说明我错了。"

**产出模板**

```
我的判断：____
我押：__%
什么会证明我错：____
期限：____
```

**判分**：看"反证条件是否真的可观察"。写了"如果大家不支持我"，那是无效反证——谁算"大家"？改成"如果三个以上的同事在群里明确反对"。

### 第 4 周：归因分摊 + 环境改动

**目标**：把前两周的能力落到行为上。

**任务 A：归因饼图**（每周 2 次）
对一件有结果的事，画四块：我的行为 / 他人的行为 / 环境 / 运气。给百分比，且四块加起来必须是 100。

**任务 B：一个 if-then + 一个环境改动**（每周 1 组）

```
如果（具体触发：时间 + 地点 + 在场的人 + 什么信号），
我就（一个动作，≤30 秒能启动）。
环境改动：____（把默认选项改掉）
本周触发次数：__ / 做到次数：__
```

**判分**：看**触发率**，不看意愿。没触发 = 触发条件不够具体，回去改条件。

## 四、计分

### 1. 校准分（核心指标）

用最简单的算法：把你所有"押了百分比"的预测按区间分组，看实际发生率。

| 你押的区间 | 实际发生了多少 | 判断 |
|---|---|---|
| 60-70% | 60-70% | 校准良好 |
| 60-70% | 30-40% | 系统性过度自信 |
| 60-70% | 85-90% | 系统性过度谨慎 |

要求：**至少 20 个样本**才看结论。少于 20 个，波动比偏差大。

更严格的做法是 Brier 分（越低越好）：`平均((你押的概率 - 实际结果)²)`，实际发生=1，没发生=0。它的好处是**惩罚"高信心 + 错"**，这正是最贵的错误。

### 2. 判定率

被现实判定过的命题 / 全部命题。低判定率说明命题写得太糊——这是最常见的问题，也是最容易改的。

### 3. 规则数

进入"规则本"的可复用规则条数。一条合格规则要满足：一句话、别人能听懂、能用在别的场景。

不合格的例子："我要更自信。"
合格的例子："我在谈重要的事之前，先写下我想让对方做的那个具体决定。"

### 4. 记账表（一周一张，别做复杂）

```
日期 | 命题或预测 | 我押 | 结果 | 偏差方向 | 归到哪一类错
11-18 | 明天评审会超时 30 分钟以上 | 65% | 真（超了 40 分钟） | 偏低 | 概率化
11-19 | 对方 2 小时内回消息 | 80% | 假 | 偏高 | 概率化
```

## 五、错题本

每次对账后，把偏差归到四类之一。归类的价值在于：**它告诉下一周该练什么**。

| 错误类型 | 表现 | 下一周加练 |
|---|---|---|
| **命题化错** | 预测写了，但没法判定真假 | 把每条命题压到"具体时间+可观察结果" |
| **概率化错** | 数字长期系统性偏高或偏低 | 先按基准率给一个初始值，再调整 |
| **反证漏** | 结果出来才发现"早就有信号" | 每次判断强制写一条观察型反证 |
| **归因错** | 结果好坏都归到单一因素 | 强制画四块饼图，四块都要有数 |

错题本只记**偏差方向与类型**，不记情绪。记情绪会把它变成另一个反刍场所。

## 六、间隔复习

D1 / D7 / D30 三次，用**回忆制**，不要重读。

**做法**：合上规则本，先说出规则，再打开对照。

| 时间 | 只问三句 |
|---|---|
| D1 | 那条规则是什么？（凭记忆说） |
| D7 | 这周它在哪个场景里起过作用？没起作用的那次，差在哪？ |
| D30 | 它现在还是对的吗？有没有反例？要不要改写成更强的一条？ |

为什么要回忆制：重读会产生"我懂了"的错觉，回忆会暴露"我其实记不住"。这两者的差距，就是训练的空间。

## 七、平台期怎么办

练了两三周，分数不动，通常不是"到顶了"，是这三件事之一：

1. **样本太舒服**：预测的都是十拿九稳的事。→ 把难度提到"你大概会对七成"的区间。校准只在这个区间里能练出来。
2. **没有反馈**：事情的结果根本看不到（比如"我这个人是不是太软"）。→ 换成能看到结果的问题。
3. **只练不记**：凭感觉觉得自己在进步。→ 回到记账表，看数字。没有记录就没有训练。

---

## 八、什么时候该停

出现以下情况，停止训练，转回"处理具体的事"或建议专业支持：

- 训练变成新的自我考核（"我连预测都做不好"）——这是把工具变成了刑具
- 每天花超过 20 分钟在记账上——成本超过收益
- 焦虑明显加重，开始为每件小事做预测
- 连续两周情绪低落、失眠、功能下降

训练的目的是**让现实给你反馈**，不是**让你多一个评判自己的维度**。这条线一旦越过，立即停。
